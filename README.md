# e-plantShopping

## Project Overview

e-plantShopping is a React-based online plant shopping application. Users can browse different categories of plants, add plants to their shopping cart, adjust quantities, remove items, and view the total cart amount.

## Features

- Browse plants by category
- Add plants to the shopping cart
- Increase or decrease item quantities
- Remove plants from the cart
- Calculate item subtotals and total cart cost
- Continue shopping from the cart
- Redux state management for cart functionality

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite
